# projekt-ppmi

## Zadatak:
Model strojnog učenja za klasifikaciju Parkinsonove bolesti temeljem MR slika mozga

Machine Learning Model for Parkinson's Disease Classification Based on Brain MR Images

## Opis zadatka:

Primjenom metoda strojnog učenja u analizi slika magnetske rezonancije (MR) mozga mogu se odrediti značajke za procjenu rizika pojave i razvoja Parkinsonove bolesti. Algoritmi mogu prepoznati suptilne promjene u mozgu koje su teško uočljive ljudskom oku, automatski analiziraju velike količine podataka te smanjuju ljudsku pogrešku. Osim toga, omogućuju ranu dijagnozu, praćenje napredovanja bolesti i personalizirane pristupe liječenju, čime se poboljšava točnost dijagnoze i učinkovitost tretmana. U radu je potrebno opisati metode strojnog učenja za dijagnostiku Parkinsonove bolesti s posebnim naglaskom na klasifikaciju temeljem MR slika mozga.
Cilj ovog rada je implementirati model strojnog učenja za klasifikaciju Parkinsonove bolesti temeljem MR slika mozga. Provesti validaciju i testiranje algoritma te komentirati ostvarene rezultate i usporediti ih s postojećim istraživanjima.

PPMI: https://www.ppmi-info.org/
